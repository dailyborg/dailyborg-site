# PC-004 Reader-requested official verification through structured position-held claims

Plain description: a reader types a name; the system searches Wikidata, keeps only entities whose description is political, reads their "position held" claims, ignores positions with an end date, classifies the current position label into office, level and state with a rule table, and only then creates a profile. No model.

Prior art to check: Wikidata-based entity linking tools, Ballotpedia API, Google Civic Information (retired 2025).

Status: candidate.
