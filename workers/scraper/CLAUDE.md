# workers/scraper (dailyborg-scraper)

Reads the RSS feed list in src/index.ts every two hours and queues new stories to ingest-queue. Link dedup lives in D1 (`seen_links`, one indexed lookup per feed, no Workers KV anywhere in this worker). Each run reads `system_settings.daily_article_cap` (default 40), counts the links already queued today, and spreads what is left over the runs still to come, so the scraper never queues more than ingest is allowed to publish. Feed order rotates every two hours and stories are taken round robin, one per feed per pass. Deep mode only looks 8 items down a feed instead of 3, it never re-queues a seen link. Manual POST triggers are rate limited to one per ten minutes through `kv_store.scraper_manual_lock_until`; GET answers 405. One `ingestion_logs` row per run, only when something was queued.
